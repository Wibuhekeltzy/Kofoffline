# KOF ALLSTAR (KOFAS) — Versi Offline

Versi offline buatan penggemar dari **The King of Fighters ALLSTAR**, yang sudah tutup (*end of service*).
Server mini sudah tertanam **di dalam aplikasi**, jadi game bisa dimainkan sendiri **tanpa internet dan tanpa login**.
Lawan di mode PvP adalah bot.

> Proyek pribadi untuk preservasi dan bermain bersama teman. Tidak berafiliasi dengan Netmarble atau SNK.
> Semua hak cipta game tetap milik pemiliknya masing-masing.

---

## 📦 File yang perlu diunduh

Semua file ada di halaman **[Releases](../../releases)** (kolom kanan halaman repo → **Releases**).

| File | Ukuran | Keterangan |
|------|--------|------------|
| `KOFAS_OFFLINE_V46.apk` | ± 150 MB | Aplikasi game |
| `KOFAS_DATA_1dariN.kofas` … `KOFAS_DATA_NdariN.kofas` | ± 1,9 GB per file | Data game (gambar, suara, karakter). **Unduh SEMUA bagian.** |

Total ± 4,3 GB. Pakai Wi-Fi.

## ✅ Syarat HP

- Android **64-bit**: hampir semua HP keluaran 2019 ke atas. HP 32-bit tidak bisa.
- Ruang kosong **± 10 GB** saat memasang. Setelah selesai, file `KOFAS_DATA` boleh dihapus, dan game memakai ± 5 GB.
- Kalau di HP masih ada KOF ALLSTAR versi lama atau resmi, **uninstall dulu**.
- HP **tidak di-root** dan tidak ada aplikasi cheat (GameGuardian, Lucky Patcher, dan sejenisnya). Kalau ada, bisa muncul *Security Alert*.

## 📲 Cara install (cukup HP, tanpa laptop)

1. **Unduh semua file** dari halaman Releases. Otomatis masuk ke folder **Download**.
   Jangan ganti nama file dan **jangan diekstrak**.
2. Ketuk **`KOFAS_OFFLINE_V46.apk`**, lalu pilih **Install**.
   - Kalau diminta, izinkan *"Install aplikasi tidak dikenal"* untuk browser atau file manager kamu.
   - Kalau muncul peringatan Play Protect, pilih **Detail lainnya**, lalu **Tetap instal**.
3. Buka game **KOFAS**. Akan muncul kotak **"KOFAS Offline - pasang data game"**. Tekan **PILIH FILE DATA**.
4. Di jendela pemilih file:
   - Buka folder **Download**. Kalau belum terlihat, ketuk menu ☰ di kiri atas, lalu pilih **Download**.
   - **Tekan lama** file `KOFAS_DATA_1dari…`, lalu **ketuk file KOFAS_DATA lainnya** sampai semua tercentang.
   - Tekan **PILIH / BUKA / SELESAI** di kanan atas.
5. Tunggu proses **"Memasang data game"** sampai 100% (± 5–20 menit). Jangan matikan layar dan jangan tutup game.
6. Setelah muncul **"Data game berhasil dipasang"**, tekan **TUTUP GAME**.
7. Buka lagi KOFAS dari layar utama HP. **Selamat bermain!** 🎮

## 🛠️ Kalau ada masalah

| Pesan / gejala | Solusi |
|----------------|--------|
| *"Bagian yang BELUM dipilih: 2dari3"* | Ada file yang belum ikut dipilih atau belum selesai diunduh. Tekan **PILIH ULANG**, lalu pilih **semua** bagian. |
| *"data TIDAK LENGKAP"* / *"isi file data rusak"* | Ada file KOFAS_DATA yang terpotong saat diunduh. Bandingkan ukurannya dengan yang di Releases, lalu unduh ulang file yang ukurannya beda. |
| *"Ruang kosong HP tidak cukup"* | Hapus video atau aplikasi yang tidak perlu. |
| *"App not installed"* | Uninstall KOF ALLSTAR lama, pastikan memori cukup, dan pastikan HP 64-bit. |
| *"Security Alert (code : 2)"* | Biasanya karena HP di-root, ada aplikasi cheat atau kloning (GameGuardian, Lucky Patcher, Parallel Space, Dual Apps), atau ROM modifikasi. Buka game dari ikon aslinya dan hapus aplikasi-aplikasi tersebut. |
| *"Data download failed"* / *"Please wait"* lama | Tutup game sepenuhnya (geser keluar dari daftar aplikasi terbuka), lalu buka lagi. |

## ⚠️ Penting

- **Jangan uninstall game.** Uninstall ikut menghapus data game **dan** simpanan permainan.
  Memasang APK versi baru di atasnya (update) aman, simpanan tetap ada.
- Simpanan permainan tersimpan di HP:
  `Android/data/com.netmarble.kofg/files/kofas_server/server/progress.json`
